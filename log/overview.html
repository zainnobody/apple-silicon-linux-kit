Rollback from macOS

Use this when Fedora does not boot. It puts the stock boot.bin back. Run it on this Mac while the M3 runs macOS with the USB-C cable connected.

ssh -t m3 'sudo diskutil mount disk0s4 && cp "/Volumes/EFI - FEDOR/m1n1/boot.bin.stock" "/Volumes/EFI - FEDOR/m1n1/boot.bin" && shasum -a 256 "/Volumes/EFI - FEDOR/m1n1/boot.bin" && sudo diskutil unmount disk0s4'

The expected hash after the copy is 00efa22c96ecba6718e880d74578dd61546ecae7553a69c003f2c0d5879f555d.
